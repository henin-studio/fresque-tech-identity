03 · Diagramme

Le fait technique
schématisé.

Chaque carte de la Fresque Tech peut être lue comme un nœud dans un diagramme Simondonien. Les relations entre cartes forment le vrai sujet. Le graphisme rappelle les schémas d'ingénieur des années 60 — la clarté de la pensée se fait graphique.

07 · Principes

Règles de l'école.

· Grille 8 colonnes partout, toujours visible
· Inter 900 pour les titres, Inter 400 pour le body, Plex Mono pour les méta
· Pas d'italique, pas de small caps, pas de fioriture
· Noir pour la structure, rouge pour l'accent, bleu pour les schémas
· Tous les éléments alignés sur la grille — alignements baseline stricts
· Filets 1px noirs, bandes 6-8px pour la hiérarchie
· Diagrammes Simondoniens obligatoires pour les cartes systémiques
· Aucune image décorative, aucun ornement, aucune ombre
